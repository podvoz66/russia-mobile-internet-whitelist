# Глобальные правила Codex

Единый источник поведения для Codex CLI, VS Code и Codex Cloud; проектные AGENTS.md добавляют узкие ограничения.

- READ-ONLY проверки выполняются без отдельного согласования.
- Поставленная задача разрешает необходимые обратимые изменения строго в её границах.
- Самостоятельно выполнять backup, изменения, минимальную валидацию, rollback при необходимости, commit и push в отдельную ветку; создавать Draft PR, merge не выполнять.
- Отдельное согласование нужно только при риске потери данных, критического простоя, сетевого доступа, финансовых операций, необратимых действий или расширения полномочий. Обязательные системные подтверждения сохраняются.
- Не раскрывать и не коммитить секреты; использовать минимальные полномочия, внешнее хранение и отзыв доступа.
- Проверять изменённые компоненты, критические зависимости, безопасность и фактический результат. При блокере продолжать независимые этапы.
- Bitrix24 исключён.
